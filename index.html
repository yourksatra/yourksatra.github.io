About Me

Hai saya Nugrah Satria Bagassabirin, alangkah baiknya jika Anda mengenal saya lebih jauh.

Saya merupakan Fresh graduate dari Jurusan Sistem Informasi Universitas Amikom Yogyakarta dan lulus dengan IPK 3,88. Saya memiliki ketertarikan yang kuat dalam bidang pengembangan web, khususnya di sisi Back-End Development. Selama masa perkuliahan, saya aktif menggali peluang untuk memperdalam keterampilan teknis melalui proyek pribadi maupun dengan memaksimalkan mata kuliah. Saya memiliki spesialisasi dalam membangun aplikasi web yang efisien dan skalabel menggunakan PHP dengan Laravel maupun Codeigniter, terbiasa mengelola basis data menggunakan MySQL dan menguasai bahasa pemograman lain seperti C++ dan Python. Saya adalah pembelajar yang proaktif dan detail-oriented, serta menjunjung tinggi praktik penulisan kode yang bersih dan kolaborasi tim. Rasa ingin tahu yang tinggi mendorong saya untuk terus menjelajahi teknologi baru. Saat ini, saya tengah mempelajari JavaScript untuk memperkaya kemampuan saya dalam membangun solusi web yang lebih dinamis dan interaktif. Bagi saya, setiap baris kode adalah jembatan menuju inovasi, dan setiap teknologi baru adalah pintu untuk memperluas cakrawala.
